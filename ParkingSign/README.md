# Parking Sign

## Building

The Parking Sign is available in the Utilities build menu. It is a 1x1 non-tile building that must be placed on a floor and costs 25 kg of buildable raw material. A green automation signal plays the `on` animation and orders checked duplicants to move to the sign. While the signal stays green, their navigation destinations are redirected to the sign, including destinations generated by other chores. A redirected arrival does not count as arrival at the original chore destination, preventing work from starting at an unreachable location. Once at the sign, pathfinding permission checks reject routes that leave its cell, so reachability queries treat other locations as inaccessible. If no chore can proceed there, they remain idle. When the signal turns red or a duplicant is unchecked, the current navigation target is discarded rather than restored; the game can assign a fresh task as usual. Selecting the sign opens a scrollable duplicant checklist. Selections are saved with the building.

## Build

`Local.Build.props` points to the Oxygen Not Included `Managed` directory and the local mod install directory. It is machine-specific and ignored by Git. To configure another machine, copy `Local.Build.props.example` to `Local.Build.props` and update both paths.

Build from the solution directory:

```powershell
dotnet build .\ParkingSign.sln
```

When `ModInstallPath` is configured, the build copies the mod DLL, `PLib.dll` (when present), `mod_info.yaml`, and `mod.yaml` to that local mod directory.
