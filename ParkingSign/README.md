# Parking Sign

## Building

The Parking Sign and Hanging Parking Sign are available in the Utilities build menu. Both are 1x1 non-tile buildings that cost 25 kg of buildable raw material. The Parking Sign must be placed on a floor; the Hanging Parking Sign requires a ceiling tile and does not require a floor. A green automation signal plays the `on` animation and orders checked duplicants to move to the highest-priority active sign they can reach. If that sign becomes unreachable, the next-highest reachable selected sign takes over. While a sign is the active destination, the duplicant's navigation destinations are redirected to it, including destinations generated by other chores. A redirected arrival does not count as arrival at the original chore destination, preventing work from starting at an unreachable location. Once at the sign, pathfinding permission checks reject routes that leave its cell, so reachability queries treat other locations as inaccessible. If no selected active sign is reachable, no sign attracts the duplicant. When the signal turns red or a duplicant is unchecked, the current navigation target is discarded rather than restored; the game can assign a fresh task as usual. Use the game's standard priority tool to set sign priorities. Equal priorities favor the sign that spawned first. Selections and priority are saved with the building.

## Build

`Local.Build.props` points to the Oxygen Not Included `Managed` directory and the local mod install directory. It is machine-specific and ignored by Git. To configure another machine, copy `Local.Build.props.example` to `Local.Build.props` and update both paths.

Build from the solution directory:

```powershell
dotnet build .\ParkingSign.sln
```

When `ModInstallPath` is configured, the build copies the mod DLL, `PLib.dll` (when present), `mod_info.yaml`, and `mod.yaml` to that local mod directory. PO translation files in `strings` are copied to the mod's `strings` directory.
